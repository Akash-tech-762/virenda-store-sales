# Vrinda Store Data Analysis

Vrinda Store Data Analysis is an Excel-based data analytics project focused on analyzing sales performance, customer behavior, order trends, and overall business performance. The project demonstrates how Microsoft Excel can be used to transform raw business data into meaningful insights that can support better decision-making.

The project begins with data cleaning and preprocessing to ensure that the dataset is accurate, consistent, and ready for analysis. Various Excel techniques are used to identify and handle inconsistencies, organize data, and prepare it for further analysis. After cleaning the data, Pivot Tables and Pivot Charts are used to summarize and explore important business metrics.

The analysis focuses on several key areas, including total sales, number of orders, customer purchasing behavior, product performance, sales channels, categories, and demographic trends. By analyzing these factors, the project helps identify which products and categories perform better, which customer segments contribute more to sales, and how sales are distributed across different channels.

An interactive Excel dashboard is also created to present the analyzed information in a clear and user-friendly format. The dashboard uses charts, graphs, KPIs, and filters to make the analysis easier to understand and explore. Users can interact with the dashboard to view different aspects of store performance and identify important trends and patterns.

### Project Objective

The main objective of this project is to demonstrate practical data analysis skills using Excel and convert raw store data into actionable business insights. This project can help businesses understand their sales trends, customer preferences, and product performance while supporting data-driven decision-making.

This project is part of my data analytics portfolio and demonstrates my ability to work with real-world datasets, perform data cleaning, analyze business data, create visualizations, and communicate insights through an interactive dashboard.
